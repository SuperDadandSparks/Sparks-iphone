SPARKS — STRAW HAT ROBOT (Free iPhone Web App)

This folder is a complete, static, installable web app with no subscriptions, no keys and no account needed to use it. It includes the original Sparks image, an animated-drawing mode, actions (Wave, Dance, Joke, Sleep), optional spoken reactions and a ChatGPT button.

HOW TO GET SPARKS ON YOUR IPHONE HOME SCREEN FOR FREE:

1. Sign into github.com in Safari (you already connected GitHub to ChatGPT, but GitHub's own site may still ask you to sign in).
2. Create a NEW PUBLIC repository, such as "sparks-robot". Public is required for GitHub Pages on the free GitHub plan. Do not put private information in this repository.
3. Upload all the app files from the sparks_iphone folder into the top level of the repository (index.html, sparks.webp, two icon PNGs, manifest.webmanifest, sw.js). Do not upload only the ZIP file; GitHub Pages needs the extracted files.
4. Go to the repository's Settings > Pages > Build and deployment > Source: Deploy from a branch. Choose main and / (root), then Save.
5. Once GitHub Pages displays your website link, open it in Safari on the iPhone.
6. Safari Share > Add to Home Screen > enable 'Open as Web App' if available > Add.

Note: The robot in the first photo mode moves as a whole image. Animated drawing mode permits separate arm and eye animations. Audio is optional and off by default. The ChatGPT button opens ChatGPT but is not a live integrated voice API in the web app. The default app itself runs without paying, and the uploaded code and image are public if using a GitHub Free Pages repository.
